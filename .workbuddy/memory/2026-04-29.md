## 日期导航 Bug 修复 (QwenPaw meta.trade_date 兼容)
- **根因1**: QwenPaw 推送 meta.trade_date 而非 meta.date，switchDay() 读 appData.meta.date 为 undefined，导致"无历史数据"
- **根因2**: renderAll() 里 adaptData() 只用于渲染，appData 仍存原始数据（meta.date=undefined）
- **修复1**: 添加 getMetaDate() 辅助函数，兼容 meta.date 和 meta.trade_date
- **修复2**: renderAll() 里将适配后数据写回 appData，确保 switchDay/updateDateNavUI 能读到正确日期
- **修复3**: main.js API 推送保存历史时也识别 meta.trade_date
- Alpha-Q 安装在 F:\Alpha-Q\Alpha-Q Terminal\，数据在 AppData/Roaming/alpha-q-terminal/

## v3.3.1 日期导航按钮禁用 Bug 修复
- **根因**: refreshAvailableDates() 和 fetchData() 并行异步执行，fetchData 先完成→renderAll→updateDateNavUI 时 availableDates 仍为空→按钮被 disabled。refreshAvailableDates 完成后填充了 availableDates 但没再调 updateDateNavUI，导致按钮永远禁用
- **修复**: refreshAvailableDates() 的 .then 回调末尾添加 updateDateNavUI() 调用
